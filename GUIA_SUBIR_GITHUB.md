# Subir esta primera versión a GitHub

Repositorio: `gperezdev-aut/vita-lima-web`

## Método sencillo desde la web

1. Descomprime el ZIP en tu computadora.
2. Entra al repositorio `vita-lima-web`.
3. Pulsa **Add file** → **Upload files**.
4. Arrastra el contenido interno de la carpeta, no la carpeta contenedora.
5. Verifica que `package.json`, `app`, `components`, `Dockerfile` y `README.md` aparezcan en la raíz.
6. En el mensaje escribe: `feat: add initial Vita Lima public website`.
7. Pulsa **Commit changes**.

No debes subir ningún archivo `.env.local`.
