# Actualizar el repositorio desde GitHub Web

1. Descomprime el ZIP.
2. En el repositorio, elimina o reemplaza los archivos anteriores.
3. Sube todo el contenido de la carpeta directamente a la raíz.
4. Usa el commit: `feat: replace website with production-ready v1`.
5. En Contabo ejecuta `git pull`, crea `.env.local` si no existe y reconstruye el contenedor.
